Vikram & Betal: install
1. chrome://extensions -> turn on Developer mode -> Load unpacked -> pick this folder.
2. Click the extension icon (or Alt+V) to open the side panel, then pick a provider (Gemini is free) and add your key in Settings.
3. Highlight text on any page for the Ask / Explain / Translate / Summarize bar.

QR on Windows/Linux Chrome: BarcodeDetector isn't available there. Download jsQR
(npm i jsqr, then copy node_modules/jsqr/dist/jsQR.js) and replace lib/jsQR.js.
